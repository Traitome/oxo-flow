🛡️ Storage Safety · Provenance · Issue #843 / #907

Disk-Pressure Guard, Scratch Isolation & Protected Trees 磁盘压力自动守护、全局临时目录与受保护数据树

Bioinformatics runs often crash at 95% completion when BAM/FASTQ intermediates exhaust scratch storage. oxo-flow’s [engine] section enforces a live Normal → Reclaim → Hold → Abort ladder that cascades tombstones up temporary = true rules automatically, injects global tmp_dir (TMPDIR/TMP/TEMP), guards raw data via protected_data_trees, and records cryptographic sha256 provenance in checkpoint.json. 生信流程常因中间 BAM/FASTQ 撑爆磁盘而在终点前崩溃。[engine] 原生提供 Normal → Reclaim → Hold → Abort 四级磁盘压力状态机，自动级联清理 temporary = true 规则产物，注入全局 tmp_dir，通过 protected_data_trees 防止原始数据被篡改，并记录 sha256 断点溯源。
